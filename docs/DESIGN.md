# Визуальное обновление — 25 сентября 2026

Сохранена основа первого дизайна: белый фон, красные акценты, исходная структура разделов. Шапка фиксирована, имеет полупрозрачный фон и лёгкую тень при прокрутке. Отступы якорей учитывают её высоту.

Переключатель языка заменён на две доступные кнопки RU/KZ с aria-pressed, плавным индикатором и сохранением выбора. Шрифт — Geologica Variable, локально поставляемый через @fontsource-variable/geologica с расширенной кириллицей для русского и казахского текста. Предыдущие шрифты удалены.

Кольца/WebGL удалены. Hero содержит объёмную CSS-книгу: обложка, корешок, торцы страниц, закладка, отражение света и тень. Книга парит, плавно следует за курсором, обложка слегка открывается при наведении. JS сглаживание работает только до достижения положения, а движение останавливается вне экрана и в скрытой вкладке. Touch-прокрутка не перехватывается.

Разделы появляются при прокрутке, кнопки и переходы реагируют плавно. prefers-reduced-motion отключает движение книги, появления и плавную прокрутку; содержимое остаётся видимым.

Проверки текущего обновления: ESLint, TypeScript/production build, 2 frontend unit tests, 3 browser tests. Проверены RU/KZ и сохранение языка, движение книги и reduced motion, fixed header и отступы якорей. Ширины: 320/390/768/1280/1440 px; на 320/390/1440 дополнительно проверено отсутствие наложения элементов шапки. Desktop и мобильная книга проверены визуально.
