# Визуальное обновление — 25 сентября 2026

Главная переработана в редакционном стиле: тёплая бумажная палитра, бордовый акцент, serif-заголовки, открытая сетка, тонкие разделители. Новые тексты доступны на русском и казахском. Общие цвета и поверхности перенесены в кабинеты.

Hero содержит собственную WebGL-сцену: два освещённых объёмных кольца, медленное вращение, сглаженная реакция на указатель. Внешних 3D-библиотек, API и платных ресурсов нет. Рендер ограничен 30 кадрами/с и DPR 1.25; при скрытой вкладке или вне viewport цикл остановлен. prefers-reduced-motion оставляет статичный кадр; без WebGL видна CSS-композиция. Touch не перехватывается.

Проверено: ESLint, TypeScript/production build, 2 unit tests, 2 новых browser tests (responsive RU/KZ + WebGL/reduced motion), существующий landing browser test. Визуально проверены 1440 px и 390 px; горизонтальная прокрутка проверена также при 768 и 1280 px.
