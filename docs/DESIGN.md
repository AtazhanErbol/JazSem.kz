# Визуальное обновление — 25 сентября 2026

По обратной связи владельца возвращена основа первого дизайна: светлый фон, красный акцент, прежняя структура разделов и карточек. Добавлены мягкие цветовые поверхности, выразительный заголовок, более плавные hover-состояния и плавающие подписи у 3D-композиции. Предыдущая редакционная тема с serif-заголовками удалена.

Шрифт — Golos Text Variable, локальный пакет @fontsource-variable/golos-text с latin/cyrillic/cyrillic-ext. Он применяется ко всему интерфейсу; внешние font CDN не используются. Неиспользуемый Manrope удалён.

Сохранена WebGL-сцена: два освещённых объёмных кольца в красном и светлом цветах, медленное вращение, сглаженная реакция на курсор. Внешних 3D-библиотек и платных API нет. Рендер ограничен 30 кадрами/с и DPR 1.25; вне viewport и в скрытой вкладке цикл остановлен. prefers-reduced-motion оставляет статичную композицию; без WebGL виден CSS fallback. Touch-прокрутка не перехватывается.

Проверено для текущего обновления: ESLint, TypeScript/production build, два browser tests (адаптивность RU/KZ и WebGL/reduced motion), screenshots desktop 1440 px и mobile 390 px. Отсутствие горизонтальной прокрутки проверено также при 768 и 1280 px.
