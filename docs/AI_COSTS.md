# Экономичный AI-режим

С 23.10.2026 также доступен `AI_PROVIDER=gemini` с `gemini-3.1-flash-lite`. Для него используются отдельные ключ, модель и цены; см. [настройку Gemini](GEMINI_SETUP.md). По запросу владельца локальная настройка `GEMINI_APP_LIMITS_ENABLED=false` отключает для Gemini бюджетную блокировку, суточное число генераций, лимит символов источников и ограничение выходных токенов приложения; учёт расхода сохраняется. Ниже приведён первоначальный профиль OpenAI, который сохраняется для ручного выбора. Автоматического перехода между провайдерами нет.

Подтверждённые отказы API (включая 429 из-за баланса или частоты запросов) возвращают резерв этого запроса. Сетевые сбои с неопределённым результатом сохраняют резерв. Ответ, оборванный лимитом выходных токенов, учитывает подтверждённые токены. Повторные платные обращения автоматически не выполняются.

По просьбе владельца выбран `gpt-5-nano`. Официальная цена на дату настройки 2026-09-25: $0.05 за 1 млн входных и $0.40 за 1 млн выходных токенов. Модель поддерживает Structured Outputs. Источник: [страница GPT-5 nano](https://developers.openai.com/api/docs/models/gpt-5-nano). Для курса по источникам это экономичный стартовый вариант; качество сложных дисциплин и казахского языка необходимо проверить на собственных материалах. Автоматического перехода на более дорогую модель нет.

`AI_ENABLED=false` по умолчанию в шаблоне настроек. Реальная доступность определяется конфигурацией запущенных процессов. `.env` исключён из Git, Docker build contexts и пользовательского архива. Секрет не включается в frontend. Проверка интеграции Gemini выполняется на синтетических материалах; оценка приложения не подтверждает фактическую оплату провайдера.

С 23.10.2026 ограничение длительности обработки снято: SDK использует `timeout=None`, ИИ-задачи не ограничены временем Celery, PDF и OCR не прерываются по таймеру. Статус работающей задачи продлевается фоновым heartbeat. Модель `gpt-5-nano` и `reasoning.effort=low` сохранены. Суточные квоты, бюджет, число токенов и ограничения размера источников относятся к расходам/объёму и остаются прежними. Внешний провайдер и сеть по-прежнему могут завершить соединение с ошибкой.

Настроены ограничения в `.env.example`:

- 40 000 символов источников на генерацию; превышение отклоняется, материалы не обрезаются молча.
- 8 000 выходных токенов на курс, 4 000 на повторную генерацию темы; лимит включает reasoning tokens.
- `reasoning.effort=low`; SDK retries=0. Доставка в брокер ограничена пятью попытками, безопасное выполнение до provider boundary — тремя. После возможного платного вызова автоматического повтора нет.
- Пять заданий в сутки на преподавателя; общий бюджет приложения $0.25 за UTC-сутки.
- Бюджет резервируется транзакционно до каждого обращения к API, включая отдельно запрошенную регенерацию. Оценка использует консервативную границу UTF-8 bytes + schema + margin. После успешного ответа резерв заменяется фактическими токенами. Неопределённый/ошибочный запрос сохраняет резерв до конца суток.
- Стоимость модели не задана → запрос блокируется. Платные встроенные инструменты не используются. OCR выполняется локальным Tesseract.

Пример: 10 000 входных + 4 000 выходных токенов — примерно $0.0021 по указанным тарифам. Это пример, не обещание цены полного курса. Reasoning, повторы и размер курса влияют на расход. Большой курс может не уложиться в лимит ответа: запрос завершится ошибкой, автоматического расширения лимита нет.

Для включения задайте `AI_ENABLED=true` и перезапустите API/worker. При смене модели обязательно обновите цены и совместимый reasoning effort. Бюджет приложения не управляет расходами других приложений с тем же ключом; используйте отдельный OpenAI project/key и проверьте account/project billing controls. Ключ, отправленный в чат, рекомендуется перевыпустить перед реальным запуском.
