# Ошибка ИИ и просмотр документа — 23.10.2026

## Причина отказа ИИ

Последняя пользовательская генерация завершилась через 4.84 секунды: журнал heavy worker показывает HTTP 429 от OpenAI. Это не таймаут. Один минимальный диагностический запрос к той же модели подтвердил `credit_balance_exhausted`, тип `insufficient_quota`. Диагностический запрос также отклонён; его резерв бюджета возвращён. Повторная генерация пользовательского курса не выполнялась.

Для дальнейшей генерации необходимо пополнить баланс OpenAI API. Настройки модели (`gpt-5-nano`, effort `low`) и отключённые ограничения длительности сохранены. Изменять модель или ключ для исправления интерфейса не потребовалось.

Официальное описание кодов: https://developers.openai.com/api/docs/guides/error-codes

## Изменения обработки ошибок

- Безопасные коды отдельно описывают баланс, квоты, spend limits, частотные ограничения, ключ/доступ/модель, локальный бюджет и неполный результат.
- Подтверждённые HTTP 400/401/403/404/422/429 освобождают только резерв отклонённого запроса; стоимость — 0, статус учёта — REJECTED.
- HTTP 408/5xx и сетевые сбои остаются неопределёнными: резерв сохраняется, автоматического повторного обращения нет.
- Неполный ответ с известными токенами учитывает их стоимость; исчерпание лимита токенов отображается отдельно от длительности обработки.
- Отказы локального бюджета/конфигурации больше не маркируются неопределённым платным результатом.
- Сообщения локализованы на русский и казахский; тело ошибки провайдера не показывается пользователю.
- Старые записи ошибок, курсы, источники и учебные данные не переписаны. Предыдущая запись FAILED остаётся историей предыдущей попытки; после исправления баланса следует создать новую генерацию.

## Причина смещения окна

Длинное имя файла без пробелов задавало минимальную ширину flex-заголовка больше ширины `dialog`. При автофокусе на кнопке закрытия браузер прокручивал диалог по горизонтали, обрезая начало заголовка и весь текст слева. Ошибка воспроизведена в Chromium с настоящим компонентом Modal и синтетическим текстом.

Заголовку заданы `min-width: 0`, перенос длинных слов и гибкая ширина; кнопка закрытия не сжимается. Область содержимого ограничена шириной окна, а сетка просмотра документа использует `minmax(0, 1fr)`.
