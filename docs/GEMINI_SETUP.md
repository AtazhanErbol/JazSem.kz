# Подключение Google Gemini

JazSem поддерживает генерацию курса и повторную генерацию темы через Gemini REST API. Ключ передаётся только сервером в заголовке `x-goog-api-key`; frontend и API статуса его не получают. Дополнительный SDK не требуется. OpenAI остаётся отдельным доступным провайдером, автоматического переключения между ними нет.

В существующем `.env` задайте:

```dotenv
AI_ENABLED=true
AI_PROVIDER=gemini
GEMINI_API_KEY=your-key
GEMINI_MODEL=gemini-3.1-flash-lite
GEMINI_THINKING_LEVEL=minimal
GEMINI_APP_LIMITS_ENABLED=false
GEMINI_INPUT_PRICE_PER_MILLION=0.25
GEMINI_OUTPUT_PRICE_PER_MILLION=1.50
```

Не заменяйте остальные настройки `.env`. Дождитесь окончания активных генераций и обработки источников перед сменой провайдера: задачи используют настройки своего worker. Затем из корня рабочего репозитория выполните:

```powershell
docker compose up -d --no-deps --no-build --force-recreate backend celery heavy beat
```

Для запуска без Docker `config.settings.local` также читает `GEMINI_*` из `.env`/`.env.local`. Перезапустите локальные процессы после изменения настроек.

## Квота и расходы

По [тарифам Google](https://ai.google.dev/gemini-api/docs/pricing) для `gemini-3.1-flash-lite` предусмотрен бесплатный уровень. Доступная квота и ограничения частоты зависят от проекта Google; приложение не может сделать её безлимитной или принудительно выбрать бесплатную оплату. Подключение ключа не включает billing Google.

Цены выше — консервативная оценка по платному тарифу ($0.25 за миллион входных, $1.50 за миллион выходных токенов). Она используется для учёта расходов и не подтверждает реальный счёт Google. На бесплатном уровне фактическая стоимость может быть нулевой. Выходные токены включают `thoughtsTokenCount`. Старые записи расходов и резервов не пересчитываются при смене провайдера.

По запросу владельца в локальном Docker включён `GEMINI_APP_LIMITS_ENABLED=false`: Gemini не блокируется суточным бюджетом JazSem, числом генераций в сутки или лимитом символов исходного текста. Проверки лимита символов отключены при извлечении, создании снимка и выполнении генерации. В `generateContent` не передаётся `maxOutputTokens`, поэтому действует предел самой модели вместо прежних 8 000/4 000 токенов приложения. Для `gemini-3.1-flash-lite` Google указывает [65 536 выходных токенов и 1 048 576 входных](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite).

Учёт подтверждённых токенов и стоимости продолжается. Резерв до ответа — предварительная оценка, которая без потолка ответа не является верхней границей. API статуса возвращает `daily_budget="unlimited"`; интерфейс показывает, что дневной лимит расходов JazSem отключён. Квоты аккаунта Google продолжают действовать. Настройка не включает оплату Google и не меняет модель.

Значение по умолчанию в исходниках и `.env.example` — `true`: его можно вернуть для повторного включения ограничений JazSem. Режим относится только к Gemini. Ограничения обработки форматов файлов, проверка структуры курса/цитат и защита от повторного одновременного запуска одного курса сохраняются.

Подтверждённый отказ возвращает резерв запроса. При сетевой ошибке с неизвестным результатом резерв сохраняется, повтор автоматически не выполняется. Ошибки ключа, квоты, отключённого сервиса и блокировки ответа показываются отдельно на русском и казахском.

## Формат и проверка

Запрос использует `generateContent` с JSON Schema и минимальным thinking. Вложенные `maxItems` исключены только из отправляемой схемы: Google отклоняет слишком сложные ограничения декодирования. Все ограничения исходной Pydantic-схемы, допустимые ответы тестов и ссылки на исходные фрагменты проверяются внутри JazSem до сохранения черновика. Основание: [ограничения structured outputs](https://ai.google.dev/gemini-api/docs/structured-output#limitations).

Курс создаётся как черновик, публикация остаётся отдельным действием преподавателя. Источники обрабатываются как недоверенный текст. Ограничения времени приложения сняты (`timeout=None`, без лимита времени Celery для AI); Google и сеть могут прервать запрос. Лимиты токенов приложения, символов источников и суточного бюджета применяются к Gemini только при `GEMINI_APP_LIMITS_ENABLED=true`.

Для ручного возврата к OpenAI задайте `AI_PROVIDER=openai` и пересоздайте те же процессы. Используются прежние `OPENAI_MODEL`, `OPENAI_REASONING_EFFORT`, ключ и цены `AI_*_PRICE_PER_MILLION`; Gemini их не заменяет.

## Проверка подключения 23.10.2026

Реальные запросы к `gemini-3.1-flash-lite` на синтетическом казахском тексте успешно создали курс на одну неделю с заданием и тестом, затем обновили тему. Обе операции прошли Pydantic-проверку и проверку ссылок на фрагменты. Первая генерация заняла 83.14 секунды. Подтверждённые токены: курс — 361 входной / 460 выходных, обновление темы — 567 / 391. Рабочие курсы в этой проверке не изменялись.

Общий backend-набор: 327 passed, 8 PostgreSQL-only skipped; тесты выполнялись на изолированной SQLite в памяти с тестовыми ключами. Frontend: 39 passed; ESLint, TypeScript/production build, Ruff и Django system check прошли. После пересоздания контейнеров API статуса подтвердил `enabled=true`, `configured=true`, `worker_available=true`, модель `gemini-3.1-flash-lite`; оба Celery worker ответили на ping. Сайт, health и readiness вернули HTTP 200. Ключ отсутствует в отслеживаемых и новых неигнорируемых файлах.

После отключения ограничений: backend 332 passed / 8 PostgreSQL-only skipped, frontend 41 passed; Ruff, ESLint, Django check и сборка TypeScript/Vite прошли. Изолированные тесты проверили извлечение текста, снимок источников и worker с лимитом символов 2, повторную генерацию курса после суточного лимита 1, бюджет 0 с сохранением учёта фактического расхода и отсутствие `maxOutputTokens` в запросах курса/темы. Отдельная проверка подтверждает сохранение ограничений OpenAI. Docker API возвращает `daily_budget="unlimited"`, heavy worker видит `limits_enabled=false` и нулевые лимиты времени AI-задач.
